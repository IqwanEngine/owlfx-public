---

## 🏛️ Gambaran Keseluruhan Ekosistem

Repositori `owlfx-public` merupakan lapisan antara muka awam (*Public Client Layer*) bagi ekosistem dagangan OWLFX. Dibina menggunakan seni bina **Multi-Page Single-Page Application (SPA)** berprestasi tinggi, platform ini dioptimumkan untuk memproses interaksi ribuan pedagang harian tanpa membebankan pangkalan data teras. 

Platform ini direka dengan tema korporat eksklusif — **Obsidian Matrix & Liquid Gold** — memberikan pengalaman UI/UX yang premium, pantas, dan mesra pengguna.

## 🎓 Modul Pembelajaran & Pendidikan (Masterclass Hub)

Direktori `/education` mengintegrasikan bilik darjah modular untuk melatih pedagang berdisiplin tinggi. Melalui sistem kandungan video penstriman terbenam (*embedded inline streaming*), pengguna mendapat akses kepada:

*   **Silibus Berperingkat:** Pembelajaran terstruktur bermula dari pengenalan asas pasaran kewangan (Forex/Gold) hinggalah ke tahap eksekutif pengurusan dana.
*   **Penguasaan Smart Money Concepts (SMC):** Modul khusus yang membedah struktur pasaran institusi, zon kecairan (*liquidity*), dan manipulasi pasaran.
*   **Pengurusan Risiko Institusi:** Latihan praktikal tentang pengiraan saiz lot, nisbah risiko-ganjaran (*Risk:Reward*), dan psikologi dagangan.
*   **Sesi Mentorship Langsung:** Integrasi jadual dan pautan untuk kelas penstriman langsung (Live Trading) bersama barisan tenaga pengajar rasmi OWLFX.

## ⚙️ Teknologi & Prestasi (Enjin Teras)

Dikuasakan oleh **IqwanEngine**, platform ini menggabungkan pelbagai teknologi moden untuk memastikan kelajuan dan kestabilan maksimum:
- **Frontend:** React + TypeScript untuk komponen yang kukuh dan boleh diguna semula.
- **Styling:** Tailwind CSS untuk reka bentuk responsif yang mematuhi sistem reka bentuk *Obsidian Matrix*.
- **Deployment:** Vercel Edge Network membolehkan penyampaian kandungan (CDN) dengan kependaman (*latency*) yang sangat rendah ke seluruh Asia Tenggara.
